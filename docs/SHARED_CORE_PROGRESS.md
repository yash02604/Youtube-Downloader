## Comparison and integration
All 13 copied application Python modules other than gui.py are AST-identical
to the canonical baseline. Only gui.py, the new responsiveness tests and this
phase's documentation were integrated. Generated bytecode was excluded.
The ZIP tests globally replaced sys.modules dependencies; these replacements
were removed so full-suite discovery imports the real application modules.

Idle 250 ms ticks no longer enumerate downloads. Progress/status events request
one pending refresh, and a two-second fallback handles missed notifications.
Existing incremental Treeview updates and selection handling are retained.
Tool discovery executes on one background worker; the UI tick applies results.
Existing executable fingerprint caches are retained.

## Initial shared-core step
core.manager exposes the existing single engine and analyzer without importing
Tkinter. core.events defines frozen, JSON-serializable progress/status events,
subscription and unsubscription. Desktop consumes these through its bounded
refresh queue. Legacy engine callbacks remain compatible. Subscriber execution
is synchronous on workers, so consumers must enqueue and return promptly.
The adapter deliberately avoids snapshotting/scanning downloads on each event.

This is the first incremental extraction, not a completed core migration.
Engine implementation, models and persistence still live in legacy modules.
Events currently contain ID, kind, status and byte counts; richer metadata and
atomic snapshots remain future work. There is no FastAPI service or frontend.
No claim is made that live YouTube authentication failures are resolved.

## Evidence and limits
Idle scan frequency changes from four times/second to approximately once/two
seconds (87.5% fewer idle scans). This is code-path evidence, not a measured
startup-time or throughput improvement. No fragment concurrency, HTTP chunk
size, quality selector, muxing, persistence or lifecycle behavior was changed.
No live downloads were performed for this integration.
Manual Windows startup, tool status, selection retention and interaction during
download remain to be measured. Installer build/install has not been rerun.
